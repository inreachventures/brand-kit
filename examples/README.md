# Examples

These are worked examples of the brand-kit skill. Brindlewick is a fictional company, and its
founders, competitors and website are invented; the brand folder was produced by running the
skill end to end, stage 0 to stage 6, with a founder played from a short brief.

The competitor research in `research/competitor-analysis.md` is thinner than a real run would
produce. The competitors are as fictional as the company, and the run had no web access, so there
were no real websites to read; it works from the founder's descriptions alone.

Start with [brindlewick/brand/README.md](brindlewick/brand/README.md).
