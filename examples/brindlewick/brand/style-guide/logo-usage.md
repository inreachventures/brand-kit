# Logo usage

Brindlewick's logo is a wordmark: the name set in IBM Plex Serif Bold, generated by the brand-kit
assets build, with a square tile showing a "B" on workshop steel for avatars and favicons. There is
no symbol yet; `designer-brief.md` is ready for when there is budget for one. The source of every
file is `style-guide/tokens.json` and `assets/config.json`; the files are rebuilt with the
`assets` command.

## Variants

Each PNG comes in 160, 400 and 1200 px widths.

| Variant | Files | Use it for |
|---------|-------|------------|
| Wordmark for light backgrounds | logos/logo-on-light.svg, logos/logo-on-light-160.png (also -400, -1200) | The website header, documents, slides, invoices: anything on paper or white |
| Wordmark for dark backgrounds | logos/logo-on-dark.svg, logos/logo-on-dark-160.png (also -400, -1200) | Workshop steel or ink backgrounds: banners, dark website sections, the footer |
| Single colour, black | logos/logo-mono-black.svg, logos/logo-mono-black-160.png (also -400, -1200) | One-colour print: stamps, receipts, forms, engraving |
| Single colour, white | logos/logo-mono-white.svg, logos/logo-mono-white-160.png (also -400, -1200) | Over photographs, and anywhere only white can be printed |
| Square tile | logos/mark-tile.svg, logos/mark-tile-160.png (also -400, -1200) | Social avatars, app icons, the email signature |
| Favicons | favicons/favicon.svg, favicon-16.png, favicon-32.png, apple-touch-icon.png, icon-192.png, icon-512.png | The website's browser tab and home-screen icons |

Maya accepted the clear space, minimum sizes and do-nots below as proposed defaults (see
`decisions.md`).

## Clear space
Keep empty space around the wordmark at least the height of the capital "B" on every side. Around
the tile, keep at least a quarter of the tile's width.

## Minimum sizes
- Wordmark on screen: 100 px wide. In print: 25 mm wide.
- Tile on screen: 16 px (the favicon). In print: 8 mm.
Below these, use the tile instead of the wordmark.

## Do
- Use the on-light wordmark on paper (#F3F3EF) or white, and the on-dark wordmark on workshop
  steel (#434D55) or ink (#1A1D20).
- Use the tile wherever the space is square or round.
- Use the single-colour versions when only one colour can be printed.

## Do not
- Stretch, squash or rotate the wordmark.
- Retype the name in another font, or in Plex Serif by hand: always use the files.

## Which file where

| Where | File |
|-------|------|
| Website header | logos/logo-on-light.svg |
| Dark website sections and footer | logos/logo-on-dark.svg |
| Documents and slides | logos/logo-on-light-1200.png |
| Social avatar | social/avatar-400x400.png (from the tile) |
| Email signature | logos/mark-tile-160.png, loaded from the website |
| One-colour print | logos/logo-mono-black.svg |
| Browser tab | favicons/favicon.svg and favicon-32.png |
