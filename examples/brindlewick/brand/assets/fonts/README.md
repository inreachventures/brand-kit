# Fonts

In this worked example the font files are left out of the repository because they are identical
to the bundled copies: `fonts-copy` put IBMPlexSerif, IBMPlexSans and IBMPlexMono (Regular,
SemiBold and Bold `.ttf` each) here from `skills/brand-kit/fonts/`. Each family's `OFL.txt` is
kept. Run `fonts-copy` on this brand folder to restore them.
